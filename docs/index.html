Three layers of defense

Each module runs independently or together via the Shield orchestrator.

🔥

PromptFirewall

Regex-based detection with low/medium/high sensitivity. Catches classic injection, DAN jailbreaks, indirect RAG injection, encoding bypasses, unicode smuggling, and prompt exfiltration.

firewall.inspect(user_input)
🛡️

ToolSentinel

Enforces tool allowlists and denylists, blocks privilege escalation, and rate-limits calls per turn. Works with any framework that exposes a tool list.

sentinel.check_tool_call(name)
🧠

MemoryGuard

Quarantines untrusted memory writes (from tool responses, RAG chunks, or external data). Enforces TTL expiry and capacity limits to prevent poisoning across turns.

memory.write(key, value, trusted=False)

Quickstart

Up and running in under 2 minutes.

Install

pip install apexguard
npm install @apexguard/sdk

Python

main.py 
from agentshield import Shield
from agentshield.policy import Policy

shield = Shield(policy=Policy(
    injection_sensitivity="high",
    tool_allowlist={"search_web", "get_weather"},
    max_tool_calls_per_turn=5,
    on_violation="block",
))

# Inspect user input before passing to agent
shield.inspect_input(user_message)

# Gate every tool call
shield.check_tool("search_web")

# Store memory with trust level
shield.memory.write("ctx", rag_chunk, trusted=False)

TypeScript

main.ts 
import { shield } from "@apexguard/sdk";

const s = shield({
  injectionSensitivity: "high",
  toolAllowlist: ["search_web", "get_weather"],
  maxToolCallsPerTurn: 5,
  onViolation: "block",
});

s.inspectInput(userMessage);
s.checkTool("search_web");
s.memory.write("ctx", ragChunk, { trusted: false });
